# Cloud PC in a Day

> **Draft asset.** Overview extracted from the *Cloud & AI — SE Accelerators* deck

A half-day, hands-on workshop to deploy **Azure Virtual Desktop (AVD)** and **Windows 365**
for secured, scalable virtual desktops — part of the *Scale with Cloud and AI Endpoints*
motion.

## What you'll do

- Deploy Azure Virtual Desktop and Windows 365 Cloud PCs
- Configure identity and secure access with Microsoft Entra
- Deliver a secured virtual desktop experience for end users

## Audience & outcome

For EUC (end-user compute) admins. Outcome: a working, secured virtual-desktop deployment
that demonstrates the Cloud PC value proposition (Sales Stage 2).
