# Govern Azure OpenAI with APIM. Run the app on ACA.

Build a deployed, end-to-end AI request path for a React and Express application on
**Azure Container Apps (ACA)**. Use **Azure API Management (APIM)** to govern access to
Azure OpenAI, ground responses with PostgreSQL and `pgvector`, and inspect routing,
token, latency, and correlation evidence in the application.

## What you will do

- Deploy the platform and application with Bicep and PowerShell.
- Route chat and embedding requests through APIM to approved Azure OpenAI deployments.
- Enforce call rates, quotas, token limits, and managed identity authentication.
- Compare fast, balanced, reasoning, and automatic model-routing profiles.
- Inspect grounded citations, deployment details, token usage, latency, and telemetry.
- Validate the gateway and application, review production guidance, and clean up.

## Prerequisites

- PowerShell 7 and Azure CLI.
- An authenticated Azure subscription with deployment and role-assignment permissions.
- Azure OpenAI model quota.
