# Purview Data Governance — User Access Matrix

> **Draft asset.** Overview extracted from the *Cloud & AI — SE Accelerators* deck
> (May 2026). Full hands-on content is being developed.

A half-day workshop that maps out the **roles and access** required to stand up
**Microsoft Purview** for Data Governance — a quick-start user access matrix (UAM).

## What it covers

- Entra ID roles and Purview roles needed for the Purview Data Governance quick start
- Roles for **Microsoft Information Protection**
- Roles for **Data Loss Prevention (DLP)**
- Roles for the **Unified Catalog**
- Bootstrapping a new Microsoft Purview tenant for data governance

## Audience & outcome

For security / Purview admins, Fabric admins, and Entra admins. Outcome: a clear overview
of the roles required to activate Microsoft Purview for Data Governance (Sales Stage 3).
