# Fabric Data Agent — Data to Insight

> **Draft asset.** Overview extracted from the *Cloud & AI — SE Accelerators* deck
> (May 2026). Full hands-on content and repo are being developed.

A half-day, hands-on workshop ("Data Agent in a Day") that enables business users to derive
insights from enterprise data using a **Microsoft Fabric Data Agent** — a virtual analyst
that lets users interact with and gain insights from data in **OneLake**.

## Agenda (subject to change)

- Fabric overview & Data Agent value proposition
- **Lakehouse fundamentals** (hands-on)
- **Data ingestion** with Pipeline / Dataflow (hands-on)
- **Data modeling** with Warehouse (hands-on)
- **Lab — Fabric Data Agent** (hands-on)

## What you'll build

- Land and shape data in **OneLake** using Data Factory (Dataflows Gen2, Pipelines) across a bronze/silver/gold medallion structure.
- Model data with the **Fabric Data Warehouse** and auto-synced Power BI semantic models.
- Create, configure, and **publish a Fabric Data Agent** over Lakehouse / Warehouse / Semantic Model / Eventhouse sources — with table selection, agent instructions, and example queries.
- **Consume** the agent across Fabric, **M365 Copilot**, Copilot Studio, Teams, Azure AI Foundry, and as a remote **MCP server** in VS Code — with RLS/CLS security always respected.

## Audience & outcome

For data analysts and data engineers. Expected outcome: enable business users to derive
insights using the Fabric Data Agent and validate analytic scenarios — expanding use cases
on an existing F SKU or justifying a new one.
