# Content Understanding - Build a document app that can explain itself.

Trace every state transition from pull request to grounded citation in this L400
developer workshop. Build and operate a document intelligence application that
extracts structured evidence from business documents and answers questions with
validated source citations.

## What you will do

- Trace GitHub Actions, CodeQL, Copilot review, OIDC, and immutable deployments.
- Upload a synthetic PDF and inspect the asynchronous ingestion state machine.
- Route documents through Azure Content Understanding and inspect structured output.
- Follow chunking, embeddings, hybrid retrieval, and citation validation.
- Deploy the application to Azure Container Apps and test failure recovery.

## Prerequisites

- Python 3.12, Node.js 20+, and PowerShell 7.
- Azure CLI and Azure Developer CLI.
- An Azure subscription with permissions to deploy resources and assign roles.
- Synthetic workshop content only; do not upload confidential or production data.
