The **[GitHub Copilot L400 Workshop · Contoso](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/)** is a four-hour, expert-level (Level 400) hands-on afternoon at the Contoso Internal Developer Gathering, delivered by Microsoft Indonesia on **[date TBC]**, 13:00–17:00 WIB, in person at **[venue TBC]**. Under the theme *GitHub Copilot: from AI pair programmer to agentic SDLC*, you will see how GitHub Copilot really works, where it fits next to Microsoft 365 Copilot, and how to build your own agents and skills. It is for software engineers, tech leads, architects, platform, DevOps and QA engineers who already use Copilot and are comfortable with Git, pull requests and an IDE.

The first 75 minutes of the [agenda](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/#agenda) build the mental model. Module 1 traces Copilot from inline completions to agent mode, Copilot cloud agent, Copilot CLI and the GitHub Copilot app, and three ways of working with agents: collaborative, asynchronous and automated. Module 2 opens the hood: context assembly, instruction layering, models, the agent loop and enterprise guardrails. Module 3 sets a decision rule: software that must pass review, tests and a release process starts with GitHub Copilot; knowledge work grounded in email, meetings, chats and documents starts with Microsoft 365 Copilot. Module 4 defines agents and skills, maps the customization stack and ends with a live build of the `contoso-fullstack-docker` skill.

Module 5 is [hands-on](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/#labs), in pairs, on a small full-stack lab app with synthetic gas-asset data. Lab 1 builds the `meter-reading-validator` Agent Skill: it loads only for meter-reading tasks, runs its script in a throwaway Docker container and returns a severity-ranked table. Lab 2 builds two custom agents: a read-only `hsse-code-reviewer` that cites a file and line for every finding, and a `planner` that writes implementation plans but never edits code. Lab 3 is the take-home: delegate an issue to Copilot cloud agent and review the pull request like a senior engineer. Every lab ends with something committed that your team can reuse.

Module 6 opens with the [demo story](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/#demo): in VS Code, Copilot builds **JagaJalur**, a Pipeline Patrol and Work Order Hub where patrol officers log findings, HSSE supervisors triage them and critical findings become work orders with an SLA. Two kinds of skills drive it: `contoso-fullstack-docker`, the team's golden path (what we build with and how we run it), and the open-source superpowers skills (how we work: design before code, a written plan, test-driven development, root-cause debugging and evidence before "done"). The stack (React + TypeScript on Nginx, FastAPI, PostgreSQL 17) runs on Docker Compose on a laptop, and humans approve the design, the plan, every terminal command and the merge. A replay of about seven minutes is on the site.

The rest of Module 6 applies the method to Contoso. Six [app ideas](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/#ideas) for a gas transmission and distribution business, such as an HSSE incident and near-miss reporter, a city gas connection tracker and an industrial gas nomination portal, are each scoped as a two-week MVP on synthetic data. Pairs score them on a 25-point rubric, pick one and take it to a first spec with superpowers brainstorming and the `contoso-fullstack-docker` skill. The wrap-up sets out a 30-60-90-day adoption path (pilot, standardize, scale) and what to measure: Copilot usage metrics plus pull request cycle time, review time, change-failure rate and test coverage.

Everything runs locally: no cloud subscription and no Docker Desktop licence are needed. On Windows, the lab runs in Ubuntu 24.04 on WSL 2 with Docker Engine, and the web front end, API and PostgreSQL start with one Docker Compose command. Setup happens before the day: about 45 minutes including one restart, plus 15 minutes for Lab 0. You need a Copilot Business or Enterprise seat in Contoso's GitHub organization, the latest VS Code with GitHub Copilot and Copilot CLI, and a laptop with 16 GB RAM recommended (8 GB minimum), 20 GB free disk and hardware virtualization enabled. Ground rules: synthetic data only, and you own every line an agent writes. Please finish the [Prepare checklist](https://ibranibeny.github.io/contoso-ghcp-l400-workshop/#prep) by the day before the workshop.
