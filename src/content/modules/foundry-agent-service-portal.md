# Microsoft Foundry Agent Service — Portal-First Workshop

> **Draft asset.** This is a preview entry — the full, hands-on content lives on its
> own site. Use the **Open the workshop** button to go there.

Build AI agents **start to finish, entirely inside the Microsoft Foundry portal** at
[ai.azure.com](https://ai.azure.com) — no local setup required. You take a single
prompt agent (`acl-remedy-advisor`, an Australian Consumer Law remedy advisor) from a
fresh project all the way to a grounded, tool-using, evaluated, and published agent.

## What you'll do

- **Set up & tour** — enable New Foundry, create a project, deploy a model, and learn the Home / Discover / Build / Operate tabs.
- **Build a Prompt Agent** — create and chat with the agent in Agent Builder.
- **Add tools & evaluate** — wire in web search and Code Interpreter, then run an evaluation.
- **Integrate MCP tools** — connect a custom Model Context Protocol (MCP) server.
- **Ground with Foundry IQ** — ground the agent in your own policy documents.
- **Operate & publish** — configure Agent ID, monitor from the Operate tab, and publish to Microsoft 365 Copilot and Teams.

## Format

- **1 lab · 13 modules · 8 hands-on labs** — portal-first, Beginner → Advanced.
- No install needed; you work in the Foundry portal in your own subscription.
